# Harry Potter Books API

Simple project built with HTML, CSS and JavaScript that consumes the PotterDB API and displays Harry Potter books dynamically on the page.

## Features

* Fetch data from an external API
* Display book covers
* Display book titles
* Responsive card layout
* Modern UI with CSS Grid

## Technologies

* HTML5
* CSS3
* JavaScript (ES6+)
* Fetch API

## API

This project uses the PotterDB API:

```txt
https://api.potterdb.com/v1/books
```

## Preview

The application displays:

* Book image
* Book title

All data is rendered dynamically using JavaScript.
